This is a pluggable implementation of Thermal Printer PoC device where we will be able to generate an SDK file since we have selected this project module as a library instead of android application due to which we are able to generate an .aar file since it also has android resources like: color, drawables, strings, etc.

Through this pluggable implementation of .aar SDK file, we will be able to integrate this entire feature easily into any of our project by simply adding in the SDK file under the lib folder of our project.

This is an example of totally independent feature implementation not having any codebase present in the actual implememtation thus not reducing the project size and build time.

We can also use this SDK as a feature implementation to be provided to any other organisations for ease and quick development of this feature.
